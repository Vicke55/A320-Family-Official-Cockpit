# GeoFS A320 Cockpit

A custom 3D Airbus A320 cockpit for GeoFS.

## Features

- Custom 3D A320 cockpit model.
- Cockpit model downloaded directly from GitHub.
- Animated sidesticks and cockpit controls.
- PFD displays integrated with GeoFS.
- Adjustable cockpit lighting.
- Cockpit sound effects and audio filtering.
- Settings panel for adjusting cockpit position, screens, controls, lighting and sound.

## Installation

1. Install [Tampermonkey](https://www.tampermonkey.net/) or another userscript manager.
2. Download `GeoFS_A320_Cockpit_GitHub.user.js` from this repository.
3. Install the script in your userscript manager.
4. Open [GeoFS](https://beta.geo-fs.com/).
5. Select a supported Airbus aircraft.
6. The cockpit model will download automatically from GitHub.

You can also reload the model through the **Reload model from GitHub** button in the advanced settings.
